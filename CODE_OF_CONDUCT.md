# Code of Conduct

## 🤝 Our Commitment

We are committed to providing a welcoming and inclusive environment for all contributors and community members, regardless of age, background, gender, identity, or experience level.

## 📋 Our Standards

### ✅ Expected Behavior

- **Be Respectful**: Treat all community members with respect
- **Be Inclusive**: Welcome and support people of all backgrounds
- **Be Constructive**: Provide helpful feedback and suggestions
- **Be Professional**: Maintain a professional tone in all communications
- **Be Patient**: Help others learn and grow
- **Be Open-minded**: Consider different perspectives and ideas

### ❌ Unacceptable Behavior

The following behaviors are unacceptable:

- Harassment, discrimination, or bullying
- Hate speech or offensive language
- Personal attacks or insults
- Unwelcome sexual advances
- Doxxing or sharing private information
- Spam or flooding
- Intentional disruption
- Any illegal activity

## 🎯 Scope

This Code of Conduct applies to:

- GitHub issues and pull requests
- GitHub discussions
- GitHub projects
- Project repositories
- Any official project communications
- In-person events (if any)

## 📝 Enforcement

### Reporting

If you witness or experience unacceptable behavior:

1. **In Issues/PRs**: Flag the comment and describe the problem
2. **Private**: Email conduct@example.com with details
3. **GitHub**: Use GitHub's reporting tools

When reporting, include:
- Description of the behavior
- Who was involved
- When it occurred
- Context/evidence

### Response

The project team will:

1. **Acknowledge** reports within 48 hours
2. **Investigate** the situation fairly
3. **Determine** appropriate action
4. **Communicate** outcomes to relevant parties
5. **Follow up** to ensure compliance

### Consequences

Actions taken may include:

- Warning or reminder of standards
- Temporary suspension of privileges
- Permanent removal from project
- Report to GitHub Trust & Safety team
- Legal action if applicable

## 💡 Examples

### Good Collaboration

```
Issue: "The feature doesn't work as expected"

Good: "When I try X, it does Y instead of Z. Here are the steps 
       to reproduce. This might be related to the API response 
       handling. Would it help if I investigated?"

Bad:  "This code is garbage and whoever wrote it is incompetent"
```

### Constructive Feedback

```
Good: "I think we could improve performance here. Consider using 
       a Map instead of Array for O(1) lookup. Here's why..."

Bad:  "Your code is slow and inefficient"
```

### Inclusive Language

```
Good: "Hey everyone, let's discuss this feature"

Bad:  "Hey guys, let's discuss" (excluding non-male members)
```

## 🎓 Guidelines for Contributors

### When Contributing

1. ✅ Follow project guidelines
2. ✅ Be respectful to reviewers
3. ✅ Accept constructive criticism gracefully
4. ✅ Help others when they ask
5. ✅ Admit when you're wrong

### When Reviewing

1. ✅ Be constructive and helpful
2. ✅ Suggest alternatives, not just criticism
3. ✅ Acknowledge good work
4. ✅ Ask questions to understand intent
5. ✅ Be patient with new contributors

### When Discussing

1. ✅ Stay on topic
2. ✅ Listen to others
3. ✅ Share knowledge openly
4. ✅ Be honest but kind
5. ✅ Disagree respectfully

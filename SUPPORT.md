# Contributing & Support

Thank you for your interest in the File Browser Agent project! We welcome contributions of all kinds.

## 🎯 Ways to Contribute

### Code Contributions
- **Bug fixes** - Fix existing issues
- **New features** - Implement features from the roadmap
- **Skill development** - Create and share new skills
- **Performance** - Optimize existing code
- **Tests** - Add test cases and coverage

### Documentation Contributions
- **Writing guides** - Improve existing documentation
- **Examples** - Share skill examples
- **Translations** - Translate documentation
- **Fixes** - Report and fix documentation errors

### Community Contributions
- **Answer questions** - Help others in discussions
- **Report bugs** - Find and report issues
- **Share skills** - Create and share skills
- **Feedback** - Give feedback on features

## 📋 Contribution Process

### 1. Planning
```bash
# Discuss in issue/discussion first
# Comment: "I'd like to work on this"
# Wait for feedback
```

### 2. Setup
```bash
# Fork repository
# Clone: git clone https://github.com/YOUR_NAME/file-browser-agent-skills.git
# Branch: git checkout -b feature/my-feature
```

### 3. Development
```bash
# Make changes
# Run tests: npm test
# Type check: npm run typecheck
# Build: npm run build
```

### 4. Commit
```bash
# Write clear commit message
# git commit -m "type: brief description"
# Follow conventional commits
```

### 5. Pull Request
```bash
# Push to your fork
# Open PR on main repo
# Fill out PR template
# Address feedback
```

### 6. Merge
```bash
# Maintainer reviews
# Squash & merge when approved
# Celebrate! 🎉
```
